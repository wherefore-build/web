Run your company like it compiles.

Say each fact once. Wherefore generates every asset from it — the drawings, the pages, the parts lists, the documents — and refuses any change that would leave one of them stale. Nothing ships that contradicts a decision.

How it works

  1. Say it once

    Prices, dimensions, names and claims live in one source. Nothing else is allowed to type them.

  2. Generate the rest

    Plain scripts turn the source into every asset a customer, a supplier or a buyer sees. The same source makes the same files every time, because nothing in the build calls a model.

  3. Gate every change

    Before a change lands, the gate rebuilds everything and compares it with what is committed. Every file must be generated, written by a person, or a capture stamped with what it was made from — and every generated file must be current — or the change is refused, in words that say why.

  4. Prove the checks

    Each check has a proof that plants the fault it exists to catch and requires the check to name it. A check nobody has seen fail is not trusted.

What it enforces

  1. A fact exists in exactly one place. Everything else is generated from it or checked against it.
  2. The build is deterministic. Nothing in the build path calls a model.
  3. Fail loudly. A change the build cannot handle stops it; nothing improvises.
  4. A check is not trusted until it has been shown to fail.
  5. Sources versus outputs. Every tracked file is generated, authored or captured. Generated files are never hand-edited, and a capture is stamped with what it was made from.

Built inside a real company

Wherefore was extracted from Chaotic Pendulums, where one spec file makes every drawing, solid model, parts list and web page. Move a dimension and every one of them moves with it, or the build stops and names the file that did not.

The whole interface

A command line, Python's standard library, and one file that says what your corpus is.

wherefore init [DIR]
write a wherefore.json that declares nothing yet
wherefore gate [--keep]
every tracked file classified, every generated one current; puts the tree back unless --keep
wherefore gate --restamp GROUP
record a re-made capture against its sources
wherefore build
the roll: every generator, twice, compared with what is committed, and the results left in place
wherefore list
run every generator once and say what each wrote
wherefore prove [SCRIPT ...]
run the client's proofs, one at a time, in place
wherefore check retired
nothing a person reads still claims a retired value or phrase
wherefore check reach
every fact, moved one at a time, reaches what it should
wherefore check claims
every claim says only what its rule allows
wherefore hook install
a pre-push hook: no push leaves the corpus stale
wherefore hook pre-push
what the installed hook runs before a push; not for typing
