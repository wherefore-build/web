Wherefore

The brand, said once. Every page, card and slide takes its colours, type and shapes from one file, and this page is built from it too.

The look follows the name. Wherefore asks why, so the display face is a literary serif. It compiles, so the page is a terminal's black and anything a person could type is set in monospace. And one bright accent marks the point of a line, the way a passing build does.
