Changelog · Wherefore 0.5.1

Every release, newest first.

Built from the release this site pins, so a release is here the moment the site moves to it - and the build stops if a feature it ships has no words on this site.

  1. 0.5.1

    3 November 2026

    What a pre-publication review found

    The first release for PyPI. When what the engine reads is not what it expected - an answer cut short, a pointer that is not one, a file that is not JSON, a redirect to another host - it now says so in words instead of a traceback or a wrong answer, and a scan of a site fetches no more than it is told to.

  2. 0.5.0

    3 November 2026

    Every surface, held to the source

    The skill now asks where else the product is described and sets each surface up to pin the source and fail its build on a feature it does not say. A copy taken from somewhere that cannot be pinned - another site, another product - says where it came from, and wherefore check upstream fails when that source moves. Every release is said once, as data, so a changelog is built rather than kept.

    What arrived

    • Derived from elsewhere Copied something you can't pin, like a partner's spec sheet? The deploy fails the day its source changes.

  3. 0.4.0

    3 November 2026

    The skill reaches Codex

    The skill is written where Codex reads it as well as Claude Code, and held to the release in both places. What the engine does is said once, as data, so a page that describes the product keeps up or its build stops.

  4. 0.3.0

    3 November 2026

    Scan: the first win, with no setup

    Point wherefore scan at a built site, a docs folder or a live address, and it reports every value stated more than one way. It needs no configuration, and it would rather miss a disagreement than invent one.

    What arrived

    • Scan Point it at your site or docs: it finds every value you state more than one way, and where the copies disagree.

  5. 0.2.1

    30 October 2026

    What a fresh review found

    Every way a fresh review found for the gate to pass when it should fail, reproduced, fixed, and held by a test that plants it. A flag a command does not take is refused, not ignored. Ready to be published as open source, under Apache-2.0.

  6. 0.2.0

    30 October 2026

    The skill ships with the engine

    A coding agent learns the rules from the release itself, and starts a corpus with you: one fact, end to end. The copy in a repository is generated, so it moves with the pin.

    What arrived

    • The skill, for Claude Code and Codex Claude Code or Codex learns the rules from a skill that ships with each release.

  7. 0.1.1

    28 October 2026

    Wherefore on Wherefore

    The engine became a client of itself. Its commands and its principles are said once, its own README is built from them, and it is judged by the release before it, the way a compiler builds itself.

  8. 0.1.0

    28 October 2026

    The first release

    The machinery that keeps a hardware company's documents true, moved out of the pendulum it was built for: generators, the coverage gate, proofs, retired facts and reach, proved against a fictional company.

    What arrived

    • Start a corpus One command starts a repository; the skill walks your agent through the first fact.
    • The gate On every push, each file must be built from the source, written by a person for a stated reason, or a capture stamped with what it shows. Anything else stops the change, and says why.
    • The build Every asset rebuilt from the source, the same way every time, so you see exactly what a change moves.
    • Proofs No check is trusted until it has failed: each proof plants the fault its check exists to catch.
    • Retired facts Retire an old price, name or limit once, and nothing a person reads may say it again.
    • Reach Wherefore changes each fact, one at a time, and checks that everything stating it changes too.
    • Claims Give a claim like “SOC 2 certified” a rule, and no page can say more than the rule allows.
    • The pre-push hook A push that would ship a stale document stops before it leaves your machine.
