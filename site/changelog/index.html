  26. 0.1.0

    28 October 2026

    The first release

    The machinery that keeps a hardware company's documents true, moved out of the pendulum it was built for: generators, the coverage gate, proofs, retired facts and reach, proved against a fictional company.

    What arrived

    • Start a corpus One command starts a repository; the skill walks your agent through the first fact.
    • The gate On every push, each file must be built from the source, written by a person for a stated reason, or a capture stamped with what it shows. Anything else stops the change, and says why.
    • The build Every asset rebuilt from the source, the same way every time, so you see exactly what a change moves.
    • Proofs No check is trusted until it has failed: each proof plants the fault its check exists to catch.
    • Retired facts Retire an old price, name or limit once, and nothing a person reads may say it again.
    • Reach Wherefore changes each fact, one at a time, and checks that everything stating it changes too.
    • Claims Give a claim like “SOC 2 certified” a rule, and no page can say more than the rule allows.
    • The pre-push hook A push that would ship a stale document stops before it leaves your machine.
